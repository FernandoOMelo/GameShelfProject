# ADR-003 — Estimativas de duração

## Status

Aceito

## Contexto

Sites externos possuem diferentes estimativas de duração e o tempo real de cada jogador varia.

## Decisão

Armazenar três valores:

- estimativa principal;
- estimativa de conclusão;
- estimativa pessoal.

A estimativa pessoal tem precedência para planejamento quando preenchida.

## Consequência

O usuário pode adaptar o planejamento à própria maneira de jogar sem perder os dados externos.
