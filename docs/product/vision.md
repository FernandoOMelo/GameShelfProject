# Visão do Produto

## Problema

Jogadores com bibliotecas grandes frequentemente perdem a noção de:

- quais jogos estão realmente em andamento;
- quanto tempo já investiram;
- quanto tempo ainda precisam;
- qual jogo deveriam começar depois;
- quanto o backlog representa em horas.

Planilhas resolvem parte desse problema, mas exigem manutenção manual e não oferecem uma experiência adequada para registrar sessões rapidamente.

## Solução

GameShelf combina:

- biblioteca visual;
- gerenciamento de backlog;
- fila;
- registro de sessões;
- planejamento de tempo;
- análise do histórico.

## Público inicial

Um único usuário, em uma rede doméstica, utilizando:

- PC para administração e análise;
- celular para registrar sessões.

## Princípios de produto

### Baixo atrito

Registrar uma sessão deve levar poucos segundos.

### Visual

A biblioteca deve lembrar uma plataforma de mídia, com capas, banners e agrupamentos.

### Planejamento realista

Horas estimadas devem ser tratadas como estimativas, não como fatos exatos.

### Histórico

Cada sessão deve permanecer registrada para permitir análises futuras.

### Self-hosted

O sistema deve funcionar localmente na rede do usuário.

## Métrica principal

O sucesso do MVP é o usuário conseguir:

1. cadastrar seus jogos;
2. montar uma fila;
3. jogar;
4. registrar uma sessão pelo celular;
5. abrir o dashboard e entender sua situação.
