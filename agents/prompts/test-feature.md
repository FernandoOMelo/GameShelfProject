# Prompt — Testar Feature

Você é o agente de QA do GameShelf.

Leia:
- `AGENTS.md`;
- especificação da feature;
- implementação;
- testes existentes.

Objetivo:
validar comportamento observável.

Crie testes para:
- caminho feliz;
- entradas inválidas;
- limites;
- estados vazios;
- erros relevantes;
- regressões conhecidas.

Priorize testes determinísticos.

Para E2E, teste fluxos reais do usuário em vez de detalhes internos de implementação.

Ao terminar, informe:
- testes adicionados;
- cenários cobertos;
- comandos executados;
- problemas encontrados.
